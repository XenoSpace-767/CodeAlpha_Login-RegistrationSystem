# Login and Registration System — C++

A file-based user authentication system built in C++ featuring user registration, credential validation, persistent storage, and interactive menu-based login routines.

Developed as part of the **CodeAlpha C++ Programming Internship**.

---

## Features
* **User Registration:** Creates new accounts with basic password length validation.
* **Duplicate Prevention:** Checks existing records to prevent duplicate user account names.
* **File Persistence:** Stores records in `users.txt` using standard C++ File I/O stream operations.
* **Authentication:** Verifies credentials against local database files upon login.
